# brincando-com-C

Pequenos programas em C para praticar a linguagem.

## Programas

- `caraoucoroa.c`: simula jogadas de cara ou coroa entre Mary e John. O programa pede o número de jogadas e mostra o vencedor de cada uma, além do placar final. As jogadas usam `rand()` sem `srand()`, então a sequência é a mesma a cada execução.

## Como compilar e rodar

Requisito: um compilador C, como o GCC.

```bash
gcc caraoucoroa.c -o caraoucoroa
./caraoucoroa
```
